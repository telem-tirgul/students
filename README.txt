התלם שלי – אפליקציית דפי התרגול של תלם
========================================

מה יש בתיקייה
- CHANGES.txt – מה השתנה בכל גרסה.
- index.html – האפליקציה (צד תלמיד + מסך ניהול למנהלת).
- manifest.webmanifest, sw.js, icon-*.png, logo.png – מה שמאפשר "הוספה למסך הבית".

התקנה (פעם אחת)
1. ב-Supabase: SQL Editor > New query > להדביק את 63.1-telem-student-portal.sql > Run.
   בסוף ההרצה מופיעה טבלה קטנה "בדיקת אבטחה". אם יש בה שורות – לשלוח צילום.
2. ב-GitHub (חשבון telem-tirgul): ריפו חדש בשם students (Public).
3. להעלות לריפו את כל הקבצים מהתיקייה הזו (בלי התיקייה עצמה).
   עדכון לגרסה חדשה: באותו ריפו > Add file > Upload files > לגרור את כל הקבצים מהתיקייה החדשה (הם מחליפים את הישנים) > Commit changes.
4. Settings > Pages > Branch: main > Save.
5. אחרי דקה-שתיים האפליקציה בכתובת: https://telem-tirgul.github.io/students/

כניסה
- מנהלת: "כניסת צוות" למטה, עם האימייל והסיסמה של מערכת הניהול.
- תלמיד/ה: טלפון + קוד. יוצרים חשבון במסך הניהול > תלמידים > שם התלמיד/ה > "יצירת חשבון ושליחת קוד".
